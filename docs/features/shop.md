# Shop

> Moved out of CLAUDE.md on 13.10.2026 (word for word, apart from translated quotes). This file describes how the feature works and why. The rules Claude must follow while changing it are in `.claude/rules/shop.md`, which Claude Code loads by itself when a matching file is read or edited.

## Overview

See Shop section below. Wishlist (general wishes + models, deals, the Prisjakt price watch) · Quick list (Kassalapp chain prices) · Owned (what you own and owned, money chains, Try other prices, Stats). Its own nav entry (sidebar, More sheet).

## Shop Feature Detail
`/#/shop` → `ShopPage` (`src/features/shop/`), rebuilt 08.10.2026 (migration `137`) into three views, `?view=` (`bought` opens Owned): **Wishlist · Quick list · Owned** (Owned has **Things | Stats**, `?tab=stats`). Phones show no counts in the view control. The header bar keeps one row and the view switch one width on every view (owner, 03.11.2026: a tab switch never reshapes the bar): on a phone Owned's Things | Stats and its "More ways to add" menu sit in the row right under the bar (they used to add a row to it and narrow the switch); from a tablet they share the bar's row. A wishlist row lives a life: **To buy** (`status 'wishlist'`) → **Mine** (`'bought'`) → **Sold or gone** (`'bought'` + `disposal` facts). A POSSESSION = `list='wishlist' AND kind='item' AND status='bought' AND kept` (`ownModel.isPossession`); quick-list ticks are never possessions.

- **Suggested categories and default pictures** (owner, 10.11.2026: "Add more sub categories and default pictures for them if no picture found or added"): pure `shopTaxonomy.ts` (`verify-shop-taxonomy`) holds ten top categories for a Norwegian shopper with 6–12 subcategories each — rain gear and wool layers, skiing, snow clearing and the cabin, pålegg, EV charging and roof boxes among them — in English and Title Case like migration 030's seed, which is included (they share one list with the owner's own, so it is never mixed). Nothing is ever added by itself, and there is no SQL to run. The filters list only the owner's own categories (a suggestion holds nothing to filter). **A thing's picture** is its own, else its price watch's, else its subcategory's default picture, else its top category's, else its initials on the category's tint. A default picture is a lucide icon drawn large on the category's tint in the 4:3 well (`.tint-well`, a soft fall of light like Apple's placeholders; never a stock photo or an emoji); a category the owner named gets one guessed from its words (`guessPicture`: "phone", "headphone", "jacket", "kitchen", Norwegian words too — "kjøkken", "sko", "sykkel"), else its top category's.
